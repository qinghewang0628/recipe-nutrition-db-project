# Delivery Manifest

Every file listed here is part of the GitHub-ready submission unless explicitly marked as a local runtime artefact.

---

## 1. Root files

| File                   | Purpose                                                                        |
| ---------------------- | ------------------------------------------------------------------------------ |
| `README.md`            | Project overview, directory layout, environment, commands, data-flow contracts |
| `DELIVERY_MANIFEST.md` | This file: complete index and submission checklist                             |
| `Makefile`             | GNU make targets (`seed`, `test`, `demo`, `pack`, `unpack`, `load`, ...)       |
| `make.py`              | Cross-platform build driver; the single implementation behind every target     |
| `make.bat`             | Thin wrapper so `make seed` also works in Windows CMD / PowerShell             |
| `requirements.txt`     | Dependency statement: Python 3.9+ standard library only                        |
| `.gitignore`           | Excludes raw course CSVs and three oversized scale CSVs                        |

There is exactly one build implementation (`make.py`); the `Makefile` and
`make.bat` are two thin platform wrappers. No redundant shell shim is
included.

## 2. `etl/` — source code

Twelve functional modules plus `__init__.py`. All original, all English,
concise comments, Python standard library only.

| File            | Responsibility                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| `__init__.py`   | Package marker and version                                                                                |

| `units.py`      | Quantity parsing, canonical conversion, gram equivalents                                                  |
| `mappings.py`   | Build and load four lookup tables                                                                         |
| `clean.py`      | Cleaning pipeline and derived tables                                                                      |
| `profile.py`    | Field profiling and cross-table consistency checks                                                        |
| `dictionary.py` | Column dictionary generation                                                                              |
| `scale.py`      | Deterministic 1x / 5x / 20x expansion                                                                     |
| `seed.py`       | psql loaders, output manifest, raw checksum manifest                                                      |
| `verify.py`     | Fifty executable correctness assertions and their report                                                  |
| `pack.py`       | Compress / restore scale CSVs above 50 MB                                                                 |
| `pipeline.py`   | CLI orchestration of the eight-step rebuild                                                               |

immediately, but they are not committed:

```

data/scales/large/ingredients.csv
data/scales/large/steps.csv
```

Their `.csv.gz` archives are committed instead. After cloning, run
`python make.py unpack` (or `python make.py scale`) to restore them.

The five raw course CSVs are also absent by design; see `raw/NOTICE.md`.

## 7. `report/` — final report

| File                      | Purpose                                                 |
| ------------------------- | ------------------------------------------------------- |
| `PartA_Final_Report.docx` | Submission-ready English academic report in Word format |
| `PartA_Final_Report.md`   | Plain Markdown mirror for repository browsing           |

The `.docx` contains seven **native Word equation objects** (Office Math /
OMML) created with the built-in equation editor: inverse document frequency,
T-overlap, Jaccard similarity, weighted overlap score, the dietary set
predicate, quantity conversion, and winsorisation. They are editable
equations, not images or plain text. The Markdown mirror is a plain-text
rendering only.

The report is written in formal, concise academic English with numbered
sections, an abstract, references and two appendices. Formatting is plain:
Times New Roman, numbered headings, simple tables, no decorative elements.
