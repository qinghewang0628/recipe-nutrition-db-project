## Conventions

- Booleans are lowercase `true`/`false` so PostgreSQL `COPY` accepts them.
- All tables are UTF-8, comma separated, with a header; no embedded newlines.
- Downstream code references `canonical_id`; `ingredient_name_raw` is audit-only.
- `qty_*`, `merged_*` and `*_raw` are audit columns; `canonical_id` must be kept.
